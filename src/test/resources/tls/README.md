# TEST-ONLY certificates

Generated by `judge-deployment/pki/pki.sh fixtures`, valid 10 years, signed by a throwaway "My-OJ Test CA" whose
key was discarded. They exist so tests can run Postgres with TLS and a client certificate. They protect nothing and
must never be used outside tests. Production certificates are issued by `pki.sh issue-all` and never enter git.

- `ca.crt`: the test CA
- `server.*`: a server leaf (CN=localhost, SAN localhost / 127.0.0.1)
- `api-gateway.*`: a client leaf
- `pg_hba.conf`: the same rules as the `pg-hba` config in judge-deployment/docker-compose.yml
